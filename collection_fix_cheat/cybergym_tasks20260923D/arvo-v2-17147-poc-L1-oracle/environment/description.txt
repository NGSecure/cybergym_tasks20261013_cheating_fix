This is a stack out-of-bounds read that occurs while a Thread mesh-networking node is assembling an outgoing routing message to propagate its aggregated network data (the collection of learned prefixes, routes, and border-router entries a node currently holds) to a neighbor. That aggregated content is packaged, together with a short type/length header, into a small fixed-size local structure whose length field is subject to a general-purpose wire-format convention shared by every such type/length/value record in this protocol stack: a length field is treated as an ordinary count almost everywhere, except that one specific reserved value is instead read as a signal meaning "the real length lives elsewhere, in an extended follow-up field," which lets the format support records too large for the field's ordinary width. The node's own content-length bookkeeping uses a ceiling one count higher than the specification actually permits, and that ceiling happens to land exactly on this format's reserved sentinel value. When the aggregated content genuinely fills the staging structure right up to that ceiling, the generic size-computation logic that later inspects the record sees the sentinel value in the length field and concludes it must be looking at one of the rare extended-length records, so instead of using the structure's real, fixed byte size it goes on to reinterpret a couple of bytes from the very content data that was just staged as if they were an extended length count. Those bytes are ordinary payload content, not a real length, so the value produced can be arbitrarily larger than the structure's true size; that bogus, much-too-large length is then handed to the routine that copies the packaged record into the outgoing message, and the copy proceeds to read that many bytes out of the small local structure, running past its true end into unrelated stack memory, which the sanitizer catches. Lowering the content-length ceiling by exactly the amount needed to keep it away from the reserved sentinel value removes the collision entirely, so a fully-packed record's length field can never again be misread as a signal to go looking for a fictitious extended length.
