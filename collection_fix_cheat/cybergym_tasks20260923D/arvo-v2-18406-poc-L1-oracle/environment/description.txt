This is a global out-of-bounds read reached from a background reconstruction thread while unpacking transform coefficients and inverse-quantizing/inverse-transforming a coding block, immediately downstream of coefficient parsing that was performed earlier by a separate slice-parsing thread. The reconstruction step picks the correct diagonal/vertical/horizontal scan-order lookup table using a small scan-type-plus-transform-skip tag that was written into a shared, sequentially-packed coefficient-record buffer at parse time and is only consumed later, per coding-tree-block, by the reconstruction thread; the byte that goes out of bounds sits one row past the end of a tiny fixed three-row scan-order table, meaning the scan-type value reconstructed from that tag byte evaluates to a fourth, invalid orientation rather than one of the three legal ones, i.e. the reconstruction side is reading a stale or misaligned byte from the shared coefficient-record stream instead of the tag that parsing actually wrote for that block. Because the packed-record buffer's layout, and hence the offset at which each subsequent block's tag byte lands, follows directly from the transform/coding-tree partitioning geometry in effect while a block's residual data was produced, any inconsistency between the coding-tree-block granularity assumed while that data was written and the granularity assumed when the same offset is later consumed for reconstruction is enough to desynchronize the producer and consumer sides of this buffer, causing a byte that was never actually written as a scan-type tag to be misread as one and driving the subsequent table lookup out of bounds. This is directionally the same class of defect as other coding-tree-block-size-handling issues already found in this decoder, where a sequence parameter set is re-signalled reusing an identifier already bound to a previously decoded stream but carrying a different coding-tree-block size, and the decoder does not validate that the size has stayed unchanged before continuing to rely on structures and derived geometry sized for the earlier configuration; here that same missing validation would surface through the buffer-layout and offset arithmetic governing the parse-to-reconstruction coefficient handoff, a distinct downstream consumer from the ones implicated by the other, differently located overflows that trace back to the same unvalidated re-signalling gap.
