This stack decodes a JSON-encoded OPC UA value from an untrusted byte buffer, and does so by first tokenizing the whole JSON payload into a fixed-size array of lexical tokens and then walking that array to locate named object keys before reading each key's associated value. To find a particular key's value, the lookup helper scans forward through the token stream and, once it matches the key text, simply advances the current token cursor by one and reports success, on the assumption that the very next slot in the array must be the key's value token. When the attacker supplies a malformed or truncated object whose last real token is the key itself with no value following it, that assumption breaks: the cursor advances one position past the end of the region that was actually populated with tokens, yet the helper still reports success and hands that now out-of-range position back to its caller as if it were a legitimate index into the token array. The decoding routine for the higher-level value type trusts this returned index unconditionally and immediately indexes into the token array with it to read the located token's start/end byte offsets, which are ordinary small integer fields inside each token record. Because the index is one slot beyond the array's allocated extent, this read lands just past the end of the heap buffer that holds the token array, producing an out-of-bounds read whose size matches one such integer field. The underlying flaw is a missing bounds check at the point where the key-search helper turns "the key I found happens to be the last token" into a returned index: it needs to verify the advanced cursor is still strictly less than the total token count before treating it as valid, rather than only checking that a match occurred at all. Because this JSON value-decoding path is the stack's ordinary, always-compiled parser for standard OPC UA payloads rather than any fuzz-only scaffolding, a peer that sends a suitably truncated JSON-encoded value reaches this same missing check during normal protocol operation.
