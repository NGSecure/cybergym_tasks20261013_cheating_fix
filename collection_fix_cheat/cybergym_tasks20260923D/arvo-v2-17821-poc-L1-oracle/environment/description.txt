This crash occurs while an image-format parser is decoding a layered image container that organizes each layer's pixel data into fixed-size tiles, which are later copied pixel by pixel into a fully allocated in-memory image buffer for display. Before decoding a layer's tile data, the parser reads a per-pixel byte-count field straight from the input and checks it against the byte count implied by that layer's declared color-and-alpha mode (an indexed-color-plus-alpha layer, for instance, is expected to use a small, fixed number of bytes per pixel). In the crashing input, this field carries a wildly out-of-range, corrupted value instead of the small expected constant. The vulnerable code treats a mismatch here as a mere warning: it silently substitutes the mode's expected byte count for the bogus one and keeps decoding as though the input's value had been valid, rather than treating the disagreement as fatal and abandoning that layer. Because the substitution only patches the value used in the validation check, and not the logic that actually sizes and fills the tile/pixel storage from the corrupted, input-controlled count, the buffer that ends up backing the layer's pixels comes out only partially written from the input stream, with the remaining bytes never assigned any value at all. When the per-pixel compositing step later walks every pixel of that buffer unconditionally to merge it into the final output image, it reads and reuses those never-initialized bytes as if they were legitimate color or alpha samples, which is exactly what a memory-checking sanitizer flags as a use of uninitialized memory. The underlying fix removes the "silently correct it and keep going" behavior and instead makes the loader reject the layer outright (with a narrow, deliberate exception for one special layer-mask case) whenever the input's declared per-pixel byte count disagrees with what its color mode requires, closing off the path that let a corrupted, degenerate size value slip past validation and reach the memory-filling logic further downstream.
