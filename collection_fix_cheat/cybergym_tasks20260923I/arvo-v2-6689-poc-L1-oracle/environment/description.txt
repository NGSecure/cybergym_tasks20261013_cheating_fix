ImageMagick (MSan build): parsing a crafted MVG (Magick Vector Graphics) script that draws an ellipse primitive triggers a use-of-uninitialized-value read. The renderer allocates a large scratch array of primitive records with a raw heap allocation and, before any parser has populated a given record, an ellipse-segment-count helper walks that array by repeatedly advancing a pointer using a per-record "how many coordinates does this entry have" field read straight out of the still-uninitialized entry, so the loop's step count is driven by garbage heap bytes instead of a parsed value.
