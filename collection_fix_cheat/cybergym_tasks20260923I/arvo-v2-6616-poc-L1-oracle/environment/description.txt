ImageMagick (MSan build): when reading a LABEL pseudo-image, the newly acquired canvas's pixel cache is left unfilled before the label text is expanded for embedded percent-escapes; if that expansion triggers a grayscale conversion and then a whole-image signature/hash computation, the hashing routine walks the still-unfilled pixel cache and folds those uninitialized bytes into its running digest, and formatting the resulting digest as a hex string later reads that uninitialized digest data, triggering a use-of-uninitialized-value warning.
