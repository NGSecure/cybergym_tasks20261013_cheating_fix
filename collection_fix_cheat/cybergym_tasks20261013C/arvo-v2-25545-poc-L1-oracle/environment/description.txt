nDPI's TCP packet-processing fuzz target (MSan build): after an HTTP flow's protocol/content-type is classified, a heuristic that scores a hostname for domain-generation-algorithm (DGA) patterns copies the name into a fixed-size stack buffer, but both the initial bounded copy and the follow-up lowercasing loop that fills it stop one byte short of the buffer's full size. For hostnames long enough to reach that stopping point, the buffer's very last byte is never written by either step, so it keeps whatever leftover stack data was already there instead of a guaranteed string terminator. The heuristic's subsequent substring/pattern scans then walk the buffer looking for a terminator or a match and read through to that never-initialized last byte, so MemorySanitizer flags a use-of-uninitialized-value read once execution reaches it.
