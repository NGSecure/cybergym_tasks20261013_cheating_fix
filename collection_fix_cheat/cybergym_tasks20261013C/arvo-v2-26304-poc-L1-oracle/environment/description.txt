fluent-bit's msgpack-to-JSON string escaper (exercised by the msgpack_parse_fuzzer, ASan) writes a `\uXXXX`-style escape for every non-ASCII byte in an input string, after checking only that a fixed 6-byte allowance (backslash + 'u' + 4 hex digits) remains in the destination buffer. The escape text is rendered with a minimum-width, not maximum-width, hex conversion, so when the multi-byte sequence being escaped decodes to a Unicode codepoint above U+FFFF (a valid 4-byte/supplementary-plane character, or a malformed sequence that decodes past that range), the formatted escape needs five or more hex digits instead of four. Because the copy into the destination buffer is never re-checked against this longer actual length before it happens, that copy writes one byte past the end of the heap-allocated JSON output buffer.
