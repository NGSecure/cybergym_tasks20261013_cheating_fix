Qt's date/time string parser triggers an AddressSanitizer heap-buffer-overflow READ of 8 bytes while resolving the time-zone component of a parsed date/time string. Once the parser recognizes an embedded time-zone specifier, it hands the specifier off to the platform time-zone backend to compute the applicable UTC offset, which interprets the specifier as a POSIX-style transition rule and breaks that rule text apart into its constituent fields. The code performing this breakdown assumes the rule text always yields a fixed minimum number of well-formed, non-empty fields; a specially crafted, malformed rule text violates that assumption, and continuing to process the resulting short or empty fragments makes a later byte-level scan run a few bytes past the end of a small heap allocation. The crash is fully deterministic and reproduces from a single crafted input string with no prior program state required.
