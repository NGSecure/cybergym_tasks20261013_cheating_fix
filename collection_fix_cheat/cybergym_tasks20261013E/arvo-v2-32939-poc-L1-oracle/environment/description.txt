RDKit's molecule-deserialization fuzz target (ASan build): the crash happens while reconstructing an RDKit molecule from an untrusted serialized ("pickled") byte stream. The deserializer reads a ring-membership section of the stream and, for each recorded ring, reads back a list of atom indices and bond indices that are supposed to identify which already-existing atoms/bonds of the molecule belong to that ring. Those index values are taken directly from the input stream and used, without validating that they actually fall within the molecule's current atom/bond count, to index directly into per-atom and per-bond ring-membership bookkeeping that RDKit's ring-info structure keeps internally as a plain vector-of-vectors, one inner vector per atom/bond. The indexing code only grows that outer vector when the supplied index is greater than or equal to its current size; a negative index supplied by a crafted input skips that growth check entirely and is used as-is in operator[], which performs no bounds checking of its own and computes a pointer via ordinary pointer arithmetic from the negative offset -- landing on whatever heap memory happens to sit before the vector's backing storage. The code then immediately treats that arbitrary memory as if it were a live inner vector object (three pointer fields marking its begin/end/capacity) and calls push_back on it, in the very same expression that performed the out-of-bounds index. Because that memory was never actually a vector -- its bytes are unrelated heap content -- the standard library's own container-corruption instrumentation immediately recognizes the "vector"'s bookkeeping pointers as garbage (not a plausible, correctly aligned pointer triple) and the sanitizer aborts right there. This is therefore an immediate out-of-bounds write/access triggered directly by an unvalidated, attacker-controlled negative ring-atom or ring-bond index from a serialized molecule -- not a delayed corruption that surfaces later on some unrelated object; the crash fires in the same statement that performs the bad index.
