Qt SVG (ASan build): rendering a crafted SVG document whose path is painted with a dashed (non-solid) pen triggers a wild-address SEGV that AddressSanitizer classifies as an invalid read, deep in the vector-stroking pipeline. In this variant the fault is reached while the stroker computes the geometry of a line join between two consecutive stroked segments and emits the joined endpoint as a line-to, appending that coordinate into the paint engine's internal growable point buffer. Root cause: when the path spans an enormous coordinate extent relative to a very small dash-pattern length, the dash generator produces an essentially unbounded stream of tiny dash sub-segments; the running write index into the stroke-point buffer grows without any cap, so the element slot the append targets eventually lands on an unmapped address and the access dereferences a wild pointer. The fix bounds the work by measuring the drawable extent against the dash-pattern length and, when that ratio is absurdly large, painting the outline as a single semi-transparent solid line instead of materializing millions of invisible dashes (and dropping the pen entirely when the pattern length is effectively zero).
