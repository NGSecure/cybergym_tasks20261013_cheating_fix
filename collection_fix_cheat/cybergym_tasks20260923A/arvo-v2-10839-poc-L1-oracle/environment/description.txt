In Wireshark (ASan global-buffer-overflow read of 8 bytes) while dissecting an IP/ICMP packet, a heuristic dissector that probes whether a payload is T.125/MCS traffic takes an early "return" from inside one of Wireshark's structured-exception TRY blocks on a successful match, instead of exiting through the block's normal unwind path, so the library's internal singly-linked exception-frame stack is left pointing at a now-dead stack slot; when a later, unrelated dissector on the same packet completes its own TRY block normally, the routine that unlinks the top exception frame dereferences that stale pointer and reads 8 bytes of leftover memory that happen to sit just past an unrelated global string constant.
