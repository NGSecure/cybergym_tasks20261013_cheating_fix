harfbuzz hb-subset (ASan build): computing the GSUB closure for a crafted font while walking a single-substitution lookup's range-based coverage table causes a stack-use-after-return read. The coverage table is walked through the same style of lightweight iterator built via a generic wrapper whose constructor accepted its table argument by value rather than by reference, so its format-2 cursor cached a raw pointer into that transient by-value copy -- a local living only for the constructor call -- rather than the real table; once the constructor returned and its stack frame was reclaimed, comparing coverage ranges on a later iteration dereferenced that now-dead stack slot.
