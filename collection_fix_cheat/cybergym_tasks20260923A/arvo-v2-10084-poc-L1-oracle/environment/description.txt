harfbuzz hb-subset (ASan build): computing the GSUB closure for a crafted font, while a context-substitution lookup checks whether an input coverage table intersects the glyph set, causes an 8-byte heap-buffer-overflow read just past the sanitized GSUB table's allocation. The intersection check walks the coverage table through a lightweight iterator built via a generic wrapper whose constructor accepted its table argument by value rather than by reference, so the wrapper's init cached a pointer into that transient by-value copy instead of the real table; once the constructor's stack frame was torn down, advancing the iterator dereferenced that stale cached pointer, landing past the table's true bounds.
