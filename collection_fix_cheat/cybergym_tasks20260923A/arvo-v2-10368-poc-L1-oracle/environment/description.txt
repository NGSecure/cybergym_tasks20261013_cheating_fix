A use-of-uninitialized-value warning fires inside a routine that measures the total length of a path in order to lay text out along that path: it walks the path's stored verbs and points in sequence to reconstruct the path as a series of line and curve segments and accumulates each segment's length. One coordinate value pulled from the path's point storage during that walk gets carried into the segment-building structure and then immediately fed into a distance computation between two points, and the sanitizer's history shows that particular coordinate slot was never actually assigned a real value before it was read this way. Tracing further back, that memory region was originally sized and allocated for a completely different, unrelated drawing operation recorded earlier in the same fuzzed scene, and the copy step for that other operation did not end up writing to every byte of the block it acquired. Because the trailing, never-written portion of that block was later reused as if it were legitimate stored point data for this path, the length computation consumes leftover, never-initialized bytes instead of a real coordinate, and the sanitizer reports the read rather than any observable corruption.
