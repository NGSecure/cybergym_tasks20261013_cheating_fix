This is a heap out-of-bounds read triggered while ImageMagick renders a crafted MVG (vector-graphics) document that sets a stroke dash pattern on a drawn path. When the current drawing state is duplicated for a nested graphic context, the interpreter first scans the supplied dash-pattern value list to count how many dash/gap lengths it holds, stopping at a terminator condition, and then heap-allocates a fresh copy of that pattern sized from the counted length plus only a small fixed margin rather than from the pattern's true worst-case size. Later, when the stroke renderer walks this cloned pattern array to work out where along the path each dash segment begins and ends, its traversal can legitimately need to read one slot further than that fixed margin allows, so the read runs past the end of the undersized heap allocation. A dash-pattern list crafted so the counted length plus the fixed margin lands just short of what the traversal actually consumes is enough to reproduce the out-of-bounds read.
