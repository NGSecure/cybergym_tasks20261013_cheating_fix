In Skia (MSan), converting a path into a region after the path's point coordinates were edited in place following an earlier bounding-box computation leaves the cached bounding box stale, so the scan-line region builder sizes its horizontal run storage from that now-too-small cached box rather than the path's real, larger extent, and a scanline produced from the path's actual geometry then writes past the end of the allocated run storage (out-of-bounds write).
