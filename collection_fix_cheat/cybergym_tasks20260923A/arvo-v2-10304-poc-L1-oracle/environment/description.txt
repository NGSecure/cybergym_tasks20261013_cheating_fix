In libxml2 (ASan build), parsing a namespaced start-tag deep enough to hit the parser's element-nesting limit fails to check the return value of the internal call that pushes the new node onto the parsing stack; when that push instead detects the excessive nesting and hard-stops the parser, it also frees the input buffer holding the document's raw bytes, but the caller keeps going and builds the element's attributes from string spans that still point into that just-freed buffer, so an attribute-handling read touches freed heap memory.
