This is ffmpeg's iLBC (internet Low Bit Rate Codec) speech-frame decoder. Each encoded frame carries a small integer that marks where a special "state" sub-block sits within the frame; the decoder only rejects that marker when it is too small, never when it is implausibly large. Because the same marker also sets how many forward- and backward-direction prediction sub-steps the decoder believes it must reconstruct for the rest of the frame, an attacker-controlled marker that is too large inflates that step count past what the decoder's fixed-size, per-subframe gain- and codebook-selection index storage was ever sized to hold, so later sub-steps end up reading their gain- and codebook-selection indices from just past the end of that storage. Those out-of-bounds, attacker-influenced values are then used, with no range check of their own, to pick an entry out of one of several small hard-coded gain-quantization lookup tables; when the corrupted selector is large enough, the resulting table lookup runs well past the end of that (very short, fixed-size) table, landing in the padding next to an adjacent read-only global array instead — the 2-byte out-of-bounds global read AddressSanitizer flags.
