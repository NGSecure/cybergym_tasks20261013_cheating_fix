OpenThread (ASan build): deriving the Thread commissioner's pre-shared key (PSKc) from an operator-supplied passphrase concatenates a fixed salt prefix, the extended PAN ID, and the network-name string into one fixed-size stack buffer sized only for the protocol's maximum network-name length, but only the passphrase's own length is range-checked before that concatenation — an over-long network name is never rejected, so appending it overruns the buffer, a stack-buffer-overflow write later consumed by the PBKDF2-style key-derivation call.
