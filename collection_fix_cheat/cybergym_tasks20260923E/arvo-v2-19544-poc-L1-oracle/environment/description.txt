This is a stack-based buffer overflow (write) in nDPI's TLS handshake fingerprinting logic, triggered while it assembles a comma- and dash-separated fingerprint string that summarizes the negotiation parameters advertised in a captured ClientHello — its handshake version, followed by the full lists of offered cipher suites, extension identifiers, and supported elliptic curves. Each of these lists is appended to the fingerprint string one entry at a time using a formatted-print helper that is told how much space remains in a fixed-size local buffer, and the running write position is advanced by whatever length that helper reports for the entry just appended; that reported length reflects how many characters would be needed even when the space actually remaining is smaller, so the tracked write position can be pushed past the buffer's real end without any explicit bound. A ClientHello that advertises an unusually large number of cipher suites and/or elliptic curves accumulates enough formatted text that the running position for a later list entry has already exceeded the buffer's capacity, so the next formatted-print call writes past the end of the stack-allocated fingerprint buffer.
