Wireshark (WASSP wireless-AP session-protocol dissector, ASan build): a sub-TLV type value read from a crafted WASSP packet is used as an index into a fixed-size table of display-name entries, but the index-vs-table-size bounds check uses a strict less-than where it needs less-or-equal, so a sub-TLV type numerically equal to the table's entry count slips past the guard and the lookup dereferences the name field of the one-past-the-end table slot, running a global-buffer-overflow read off the end of the array.
