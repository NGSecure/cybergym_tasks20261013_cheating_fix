A bug in Capstone's capstonenext ARM/Thumb disassembler (MSan use-of-uninitialized-value) occurs because certain Thumb byte sequences decode to an internal pseudo-opcode (used to represent an implicit division-trap instruction) that has no matching row in the ARM instruction-id/operand mapping tables, so the lookup silently fails and leaves the newly heap-allocated result's public instruction-id field unset; code that later branches on that id reads uninitialized memory.
