libarchive (ASan heap-buffer-overflow read): reading a multi-volume RAR5 "solid" archive whose compressed stream continues from one volume file into the next can re-enter the volume-boundary continuation logic while an earlier continuation attempt is still unwinding; the pending executable-code (x86 branch) filter then reapplies buffer offsets and a length that were valid for the prior volume's decompression window against a freshly reallocated window sized for the new volume/entry, so it copies past the end of that much smaller buffer.
