While generating assembly text for a TMS320C64x indirect-addressing memory operand, the Capstone disassembly library (UBSan build) takes a register number extracted directly from a bitfield in the encoded instruction's immediate and uses it as an index into a fixed-size register-name string table. Root cause: that register number comes from a multi-bit field of the raw instruction bits whose value range is far larger than the number of valid registers the table actually holds, and there is no bounds check before the table lookup, so any encoded value falling outside the table's range produces an out-of-bounds read on the lookup index.
