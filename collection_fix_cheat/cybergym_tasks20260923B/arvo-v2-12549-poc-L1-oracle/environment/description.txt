In AV1 (libaom) decoding (ASan build), an inter-predicted block whose motion vector references source pixels far outside the current frame's visible boundary triggers a heap-buffer-overflow read while the SIMD-optimized pixel-copy/interpolation routine gathers the referenced source pixels for the prediction block. Root cause: the reconstructed-frame buffer reserves a fixed pixel border around the visible picture so that inter prediction can safely read pixels for motion vectors pointing outside the frame, but for this decoder build that border is sized too small to cover the reach a permissible motion vector can actually have, so the copy/interpolation routine ends up reading past the end of the allocated frame buffer.
