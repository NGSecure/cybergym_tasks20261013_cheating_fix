When Capstone (capstonenext) disassembles an X86 instruction, in cases where REX.W affects operand-width selection, getID() calls a helper that decides whether the REX.W-adjusted candidate instruction id is a 64-bit instruction; that helper indexes the global instruction-description table directly using the passed-in id as an array subscript, instead of first mapping the id to its real table index via a lookup the way the rest of the codebase does, so an id value beyond the table's actual length reads global memory past the table's end.
