Skia's Ganesh (GPU) canvas-drawing fuzz target (ASan build): a heap-use-after-free write occurs when a recorded SkPaint stored inside an SkPicture's command list is destroyed and releases a shared, reference-counted color filter that was already freed. Root cause: the same color filter is also captured by a scratch SkPaint copy kept inside SkGlyphRunBuilder's text-drawing helper, which reuses one long-lived glyph-run member for the whole lifetime of its owning canvas instead of scoping fresh storage per draw call; when a short-lived SkCanvas created only to rasterize a picture-backed lazy image is torn down early, that scratch paint's destructor drops the color filter's reference prematurely, so by the time the picture's own recorded paint copy is later destroyed during resource-cache eviction, it releases a color filter that no longer exists.
