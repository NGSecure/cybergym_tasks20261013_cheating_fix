aom AV1 decoder (UBSAN build, multi-threaded tile decoding): a bitstream-conformance check verifies that a coded block's partition size subsamples to a valid chroma block size, and is meant to abort decoding with a corrupt-frame error when it does not — but when that check runs on a worker decode thread, the abort never actually unwinds execution, so the invalid block-size sentinel keeps propagating downstream and is used as an index into a per-plane pixel-count lookup table while computing an entropy-coding context for the block's transform coefficients, producing an out-of-bounds array read.
