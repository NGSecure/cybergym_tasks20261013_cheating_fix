A crafted MVG (vector-drawing) input drives ImageMagick's shape-tracing code into a heap-use-after-free write while tessellating a curved outline (an ellipse embedded inside a rounded-rectangle primitive) into a series of points. Before appending each batch of points, the tracing routine asks a shared helper to make sure the primitive-point buffer is large enough, and only refreshes its local pointer into that buffer when the helper reports success; for this input, the point count needed for the curve balloons to an unreasonable size, so the helper's underlying reallocation fails, and as a documented fallback the underlying memory-resize primitive releases the old block before returning failure. The caller, however, does not treat that failure as fatal and does not resync its local pointer — it falls through into the point-writing loop still holding the address of the buffer that was just freed, so the very next point write lands on already-released heap memory, an 8-byte heap-use-after-free write rather than an out-of-bounds write, since the freed block's size was never actually exceeded.
