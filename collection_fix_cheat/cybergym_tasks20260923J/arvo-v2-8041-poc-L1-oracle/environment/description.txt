GraphicsMagick (MSan build): decoding a DPX image whose element list omits one of the required red/green/blue channels lets the corresponding portion of the freshly allocated pixel-cache scanline go unfilled, because the coder's channel-completeness check runs only after the per-element decode loop has already populated the cache; when that same image is subsequently serialized back out as a DPX file, the per-channel output loop walks every pixel including the channel that was never written, triggering a use-of-uninitialized-value warning.
