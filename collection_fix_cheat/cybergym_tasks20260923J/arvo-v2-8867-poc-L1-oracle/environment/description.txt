Capstone's EVM (Ethereum Virtual Machine) disassembler module (ASan global-buffer-overflow read): when the byte being decoded is the highest-valued opcode in the instruction set, the disassembler treats it as valid and looks up its per-instruction metadata in a small internal table, but that table was built one entry short of the full opcode range while the accompanying bounds check let an index equal to the table's length pass through instead of rejecting it, so the lookup reads one entry past the end of the global table.
