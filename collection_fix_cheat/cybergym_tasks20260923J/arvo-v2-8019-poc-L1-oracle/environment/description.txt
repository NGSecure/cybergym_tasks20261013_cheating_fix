ImageMagick's HEIC image decoder (ASan build): decoding a crafted HEIC/HEVC image triggers a heap-buffer-overflow read while ImageMagick's bundled HEVC decoding library reconstructs an inter-predicted picture through its vectorized, SSE-optimized motion-compensation code path. Root cause: each decoded picture's pixel buffer is allocated with a small fixed safety margin appended past its nominal size, sized for the plain scalar code path; the vectorized motion-compensation routine instead loads samples in wider 128-bit chunks than that margin was designed to absorb, so for predicted blocks that land near the tail of the buffer the SIMD load overruns the heap allocation by a few bytes and AddressSanitizer reports the out-of-bounds read.
