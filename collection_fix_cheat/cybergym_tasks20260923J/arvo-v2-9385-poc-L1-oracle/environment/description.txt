Skia (ASan build): when the raster canvas decides to draw glyphs as filled vector paths instead of via cached glyph bitmaps (e.g. because the transform is too large or has perspective), it copy-constructs a fresh paint from the same reusable glyph-run builder buffer, and that copy takes a reference on a path-effect object whose sole owner had already been destroyed when the builder's buffer got reused/rebuilt for a later draw, so incrementing the (already-freed) object's reference count performs a heap-use-after-free write.
