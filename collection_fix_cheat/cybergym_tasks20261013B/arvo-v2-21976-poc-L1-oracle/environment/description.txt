MemorySanitizer reports a use-of-uninitialized-value read inside Skia's GPU (Ganesh) rendering backend. The bug triggers while a drawn path is being converted into a canonical GPU-side shape representation: when that path's bounding rectangle degenerates to zero width or zero height (i.e., it collapses to a line), the simplification logic consults a stored bounding-rectangle field to pick which endpoints represent that line, but on the code path actually taken this field has not yet been populated for the current shape instance, so the comparison reads uninitialized memory instead of the rectangle that was actually supplied for this call. The never-initialized bytes trace back further to an earlier step, where the path's internal state is copied into the GPU shape object while it is being constructed, leaving part of that state unset before the simplification check runs downstream.
