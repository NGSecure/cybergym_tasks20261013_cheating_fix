ImageMagick's MVG (Magick Vector Graphics) script interpreter, exercised while decoding a crafted MVG document, triggers an AddressSanitizer heap-buffer-overflow (1-byte write) at an address one byte before the start of a heap buffer the interpreter allocates for its "class" macro-substitution feature: on encountering a class command that references a macro defined earlier in the same document (via a graphic-context push/pop carrying an id), the interpreter figures out how many bytes of the command stream precede the class command by stepping the current parse cursor backward past the just-read keyword plus one further byte for the separator it assumes always precedes a keyword, then allocates a fresh copy of the whole remaining command buffer and writes a NUL terminator into that copy at the computed backward offset so it can be spliced together with the macro's expanded text; when the class command is the very first token in the document, there is no separator byte before it to account for, so the backward step lands one byte before the start of the buffer being scanned, producing a negative splice offset, and the NUL-terminating write into the newly allocated copy then lands one byte before that allocation instead of inside it.
