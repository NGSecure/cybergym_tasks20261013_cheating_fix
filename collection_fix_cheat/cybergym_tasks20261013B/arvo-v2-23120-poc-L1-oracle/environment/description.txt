libxml2 (ASan build): while the streaming pull-parser (xmlTextReader) incrementally frees an element's attribute nodes to bound memory use, it fails to detach the freed attribute from the document's internal ID/reference-tracking table when that attribute was itself an XML IDREF/IDREFS target, leaving a dangling entry behind; a later end-of-document reference-validation pass then walks that table and formats a diagnostic message using the freed attribute's name, triggering a heap-use-after-free read during the message-formatting step itself.
