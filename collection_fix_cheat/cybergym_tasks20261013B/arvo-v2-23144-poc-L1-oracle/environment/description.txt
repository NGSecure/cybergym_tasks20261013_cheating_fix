libxml2 (MSan build): the streaming pull-parser (xmlTextReader) frees an attribute node without detaching the matching entry from the document's internal ID/reference-tracking table when that attribute was itself an XML IDREF/IDREFS target, leaving a dangling pointer behind; when a later end-of-document reference check reports that dangling entry, the generic error-reporting machinery's own internal string-copy step (used to persist the diagnostic's message arguments into the last-error record) reads from that already-freed and since-recycled memory, which MemorySanitizer reports as a use of an uninitialized value rather than the direct heap-use-after-free read seen when the same defect is caught by AddressSanitizer.
