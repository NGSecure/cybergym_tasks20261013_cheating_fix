OpenSC's PKCS#15 fuzz target (ASan build) exercises the private-key-operation path of a TCOS smart-card reader driver: when servicing a PKCS#15 decipher request, the driver builds an outgoing command APDU whose payload buffer is a caller-supplied ciphertext block copied into a fixed-size buffer allocated on the stack. Root cause: before copying, the driver never validates that the ciphertext length fits inside that fixed-size buffer (it is sized for a single short APDU's worth of data), so a ciphertext block larger than that capacity is copied in full, overrunning the stack buffer and corrupting adjacent stack memory during the copy.
